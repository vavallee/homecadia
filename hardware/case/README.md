# Wall-mount case

Remix of [veltoc](https://github.com/danking6/veltoc) by danking6 (MIT) for
the homecadia sensor-01 stack: XIAO ESP32-C6 + ePaper Driver Board V2 + 2.9"
panel, EC11 encoder with 20mm D-shaft, 3mm LED window, USB-C panel pigtail
opening, M2 self-tapping screw bosses.

**STLs pending** — the remixed STLs (veltoc-wallmount.zip) get committed to
`stl/` here.

## Print notes (draft — finalize in milestone 6)

- Material: PLA or PETG. PETG if mounted near heat sources.
- Orientation/supports/wall count: TBD from the remix geometry.
- Hardware: M2 self-tappers into printed bosses — don't overtighten.
